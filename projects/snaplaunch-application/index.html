snaplaunch Application
A customizable AI assistant platform that allows companies to create, train, and embed intelligent agents directly into their websites or internal tools.
See it live on a client website
YEAR
2025
COMPANY
ERANOVA
SCOPE
PRODUCT DESIGN, UI/UX DESIGN, FRONTEND DEVELOPMENT
Overview
Snaplaunch is a no-code AI agent platform that enables businesses to design, train, and deploy conversational agents with ease. These agents can be embedded into any website or used internally, helping automate customer support, marketing, recruiting, and more. I led the entire frontend design and development of the product, working in Figma, HTML/CSS/JS, Django, and WebSockets, while also contributing backend integration logic in Python. My role spanned product architecture, component design, and full implementation from scratch — closely collaborating with the backend team via Git.
Problem
Clients using Eranova’s internal AI tools wanted an easier way to launch and customize their own AI agents, without engineering support. We needed to build a product that gave them full control — visually and functionally — over deploying and managing AI agents on their own platforms, with minimal friction and a polished UX.
Design & Engineering Process
Designed the entire interface in Figma, focusing on clarity, simplicity, and brand adaptability. Built a fully responsive, cross-platform dashboard UI with systems for organization management, user roles, agent training, and usage analytics. Created agent training flows, allowing users to upload PDFs and documents to power knowledge-based AI interactions. Engineered an embeddable AI agent modal that integrates seamlessly into external sites using iframes, while overcoming challenges in WebSocket communication, particularly on iOS. Designed and implemented real-time updates and animations for a smooth, high-performance user experience. Collaborated closely with the backend team, writing SQL queries and Django-based Python logic for connecting the frontend to dynamic data endpoints. Implemented version control practices across teams, ensuring smooth merges and feature integration in a fast-paced environment.
Outcome
Snaplaunch launched recently and is now embedded on 30+ live client sites, with new users being added each week. The modular design of the embed system allows it to drop into any site effortlessly and retain both speed and brand alignment. The platform is already enabling companies to deliver AI experiences that are powerful, intuitive, and visually cohesive — and continues to evolve rapidly.
