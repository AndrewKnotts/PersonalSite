Eranova Application
A long-term redesign and refactor of the core Eranova platform — transforming a functional but fragmented internal AI tool into a clean, usable product with scalable UI patterns, responsive layouts, and a unified visual system.
YEAR
2025
COMPANY
ERANOVA
SCOPE
SOFTWARE ENGINEERING, UI/UX DESIGN
Overview
The Eranova Platform began as a simple tool that allowed companies to create "knowledge sources" from their own files, which could then be assigned to an AI Agent to make it familiar with that content. When I joined the team, the core functionality was in place — but the interface was visually inconsistent, difficult to navigate, and not built to scale.
My initial task was to design a new dashboard for clients to view their usage data. Since then, I’ve led the design and frontend overhaul of the platform — rethinking layouts and component hierarchies, creating a modular and intuitive design system, and rebuilding the frontend architecture with reusable, scalable patterns.
While the platform continues to evolve, my work has been foundational in shaping its user experience and visual identity — establishing a standard for how the team builds moving forward.
Problem
The original platform had grown organically — features were added fast, but design hadn’t kept up. Key problems: Inconsistent UI elements with no reusable structure Poor readability of data-dense views Disjointed layouts that didn’t support scalable workflows Limited visual feedback for key interactions (e.g. saving, training, uploading) The goal was to bring everything under a unified visual and component system, improve usability across the board, and make the platform feel more intuitive, responsive, and professional.
